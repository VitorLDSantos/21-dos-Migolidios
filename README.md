# Banana 21

Jogo para 2 jogadores em React, com tema de savana e macacos.
Cada jogador pega bananas (1 a 10 aleatórias). Quem chegar mais perto de 21 sem passar vence.

- 17 a 20: o número fica amarelo (perto do 21)
- 21: o número brilha em verde
- acima de 21: o número fica vermelho

## Como rodar

1. `npm install`
2. `npm run dev`
3. Abra o endereço que aparecer no terminal (normalmente http://localhost:5173)
